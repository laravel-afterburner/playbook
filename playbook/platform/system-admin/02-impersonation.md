## Overview

System administrators can **impersonate** another user to troubleshoot issues or verify permissions. While impersonating, you see the application as that user would.

## Starting impersonation

1. Open the profile menu as a system administrator
2. Choose **Impersonate User**
3. Select the user to impersonate

## While impersonating

A banner indicates that impersonation is active. Perform only the actions necessary for support or verification.

## Stopping impersonation

Choose **Stop Impersonating** from the profile menu to return to your administrator account.

## Audit considerations

Impersonation sessions should be logged in the audit trail. Use impersonation sparingly and in accordance with your organization's support policies.
