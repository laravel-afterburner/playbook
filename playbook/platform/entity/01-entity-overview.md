## What is a {{ entity_label_title }}?

In {{ app_name }}, a **{{ entity_label }}** is the primary organization unit. All members, roles, settings, and most feature data belong to a {{ entity_label }}.

Examples depend on how your application is configured — a strata corporation, company, program, or other organization type.

## {{ entity_label_title }} owner

Every {{ entity_label }} has an **owner** with full administrative access within that {{ entity_label }}. Owners can manage settings, members, and roles.

## Switching {{ entity_label_plural }}

Use the {{ entity_label }} switcher in the navigation bar to change your active {{ entity_label }}. Your permissions apply within the currently selected {{ entity_label }} only.

## Creating a {{ entity_label }}

If permitted, create a new {{ entity_label }} from the {{ entity_label }} switcher menu. You become the owner of {{ entity_label_plural }} you create.
