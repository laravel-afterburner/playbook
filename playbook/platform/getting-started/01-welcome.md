## Introduction

Welcome to {{ app_name }} **Help & Support**. This guide explains how to use the application — from signing in and managing your {{ entity_label }} to working with optional packages such as Documents, Events, Voting, and Communications.

Unlike the **Documents** library (where your organization stores files), Help & Support is built-in guidance that ships with the platform and optional packages.

## Who this is for

- **{{ entity_label_title }} owners and administrators** setting up members, roles, and settings
- **Council and staff** running day-to-day workflows
- **Owners and members** using self-service features for their lots or roles
- **System administrators** managing audit logs and impersonation

## Help & Support sections

The sidebar lists every section you can access. Typical sections include:

| Section | What it covers |
|---------|----------------|
| **Platform** | Sign-in, navigation, {{ entity_label_plural }}, roles, security, notifications, FAQ |
| **Documents** | File library, folders, uploads (when installed) |
| **Events** | Meetings, calendar, notices, action items (when installed) |
| **Communications** | Announcements and discussions (when installed) |
| **Voting** | Ballots, proxy votes, results (when installed) |
| **Subscriptions** | Billing and plans (when installed) |
| **Dashboard**, **Directory**, **Compliance**, **Properties**, **Finances**, **Insurance**, **Maintenance**, **Administration** | Strata-specific areas (when configured for strata) |

Sections appear only when the related package is installed and you have permission to use them.

## FAQ

Short answers to common questions live on the **FAQ** page (`/help/faq`) when your administrator has published entries. FAQ visibility is controlled separately from the main documentation — see [FAQ](/help/platform/faq).

## Search and contact support

Use the **Search** field at the top of any Help & Support page to find topics across all visible sections.

If you cannot find an answer, click **Contact support** to send a message to your system administrators. Include the page you were on and a short description of the issue.

## How to browse

Use the sidebar to move between sections and pages. Each page includes an **On this page** table of contents when subsections are present.
