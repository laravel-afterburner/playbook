## Main navigation

After signing in, the top navigation bar provides access to the **Dashboard** and feature areas registered for your application. Available items depend on your role, subscription entitlements, and which packages are installed.

Common main navigation items include:

| Item | Typical purpose |
|------|-----------------|
| **Dashboard** | Home base with action items, KPIs, and summaries |
| **Properties** | Private and common property registers (strata apps) |
| **Documents** | Shared file library |
| **Events** | Meetings and calendar |
| **Communications** | Announcements and discussions |
| **Voting** | Ballots and proxy votes |

Your application may show fewer items if a package is not installed, your subscription is inactive, or you lack permission.

## {{ entity_label_title }} menu

Open the {{ entity_label }} switcher in the navigation bar to manage your active {{ entity_label }} and open {{ entity_label }}-scoped pages.

### Core items

| Item | Purpose |
|------|---------|
| **Details** | Name, timezone, and core {{ entity_label }} information |
| **Members** or **Directory** | Member list and resident directory (label depends on your app) |
| **System Settings** | Package configuration for administrators |

### Grouped items (strata and similar apps)

Many strata applications organize the menu into sections:

| Section | Typical items |
|---------|----------------|
| **{{ entity_label_title }} Compliance** | Plan, Bylaws, Land Use, Covenants |
| **{{ entity_label_title }} Business** | Financials, Insurance, Maintenance |
| **System Support** | Subscriptions, Help & Support |

Other applications register items in the default placement between **Members** and **System Settings**. If you do not see an item, you may lack permission or the feature may not be enabled.

## {{ entity_label_title }} switcher

Use the switcher to change your active {{ entity_label }}. Pages for members, finances, properties, and packages are scoped to the {{ entity_label }} you have selected. Your permissions apply within the current {{ entity_label }} only.

If permitted, create a new {{ entity_label }} from the switcher menu. You become the owner of {{ entity_label_plural }} you create.

## Profile menu

Open your profile menu (top right) to access:

- **Profile** — name, email, timezone, and account details
- **Security** — password, two-factor authentication, and passkeys
- **Notifications** — in-app notification center

## Help & Support

Open **Help & Support** from the **System Support** section of your {{ entity_label }} menu (or the default menu placement in other apps). Use **Search** to find topics across sections, or **Contact support** to reach system administrators.

Members need **View Playbook** permission (or equivalent) to open Help & Support when your application enforces it.
