## Main navigation

After signing in, the top navigation bar provides access to the **Dashboard** and feature areas registered for your application. Available items depend on your role, subscription entitlements, and which packages are installed.

Common main navigation items include:

| Item | Typical purpose |
|------|-----------------|
| **Dashboard** | Home base with action items and summaries |
| **Properties** | Lots, bylaws, maintenance, insurance (strata apps) |
| **Documents** | Shared file library |
| **Events** | Meetings and calendar |
| **Communications** | Announcements and discussions |
| **Voting** | Ballots and proxy votes |

Your application may show fewer items if a package is not installed or you lack permission.

## {{ entity_label_title }} menu

Open the {{ entity_label }} switcher in the navigation bar to manage your active {{ entity_label }} and open {{ entity_label }}-scoped settings:

| Item | Purpose |
|------|---------|
| **Details** | Name, timezone, and core {{ entity_label }} information |
| **Members** | Invite, remove, and assign roles |
| **Financials** | Strata finance hub (strata apps, when permitted) |
| **Subscriptions** | Plan, billing, and invoices (when installed) |
| **Help & Support** | Return to this guide |
| **System Settings** | Package configuration for administrators |

Items between **Members** and **System Settings** are registered by optional packages. If you do not see an item, you may lack permission or the feature may not be enabled for your {{ entity_label }}.

## {{ entity_label_title }} switcher

Use the switcher to change your active {{ entity_label }}. Many pages — members, settings, documents, meetings, and finances — are scoped to the {{ entity_label }} you have selected. Your permissions apply within the current {{ entity_label }} only.

If permitted, create a new {{ entity_label }} from the switcher menu. You become the owner of {{ entity_label_plural }} you create.

## Profile menu

Open your profile menu (top right) to access:

- **Profile** — name, email, timezone, and account details
- **Security** — password, two-factor authentication, and passkeys
- **Notifications** — in-app notification center

## Help & Support

Open **Help & Support** from your {{ entity_label }} menu to return to this guide at any time. Use **Search** to find topics across sections, or **Contact support** to reach system administrators.

## Dashboard

The dashboard is your home base after login. It surfaces action items and links to areas that need your attention. Content varies by role and installed packages.
