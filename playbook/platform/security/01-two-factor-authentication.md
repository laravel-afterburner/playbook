## Overview

Two-factor authentication (2FA) adds a second step when signing in. After entering your password, you provide a code from an authenticator app.

## Enabling 2FA

1. Open **Security** from the profile menu
2. Enable two-factor authentication
3. Scan the QR code with your authenticator app
4. Enter the confirmation code to finish setup
5. Store your recovery codes in a safe place

## Signing in with 2FA

After entering your password, enter the current code from your authenticator app.

## Recovery codes

Use a recovery code if you lose access to your authenticator app. Each code works once. Generate new codes from the Security page after using one.

## Disabling 2FA

You can disable two-factor authentication from the Security page. Confirm your password before removal.
